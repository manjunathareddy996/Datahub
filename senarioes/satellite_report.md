## Lineage Pattern Comparison

```
HEALTH multi-source ma_sat (NO stitch):
  source_table → stg1 (1:1) → stg2 (1:1, own hashdiff) → sat (ma_sat UNIONs all stg2s)
  
PARTNER union-view sat (NO stitch):
  source_table → stg1 (1:1) → stg2 per source (1:1, own hashdiff) → stg2_std_union__* (UNION ALL) → sat

HEALTH/PARTNER stitch-backed sat (WITH stitch):
  source_table₁ → stg1₁ ─┐
  source_table₂ → stg1₂ ─┼── stitch (COALESCE, 1 row per key) → stg2 (1 hashdiff) → sat
  source_tableₙ → stg1ₙ ─┘
```

Stitch-backed is the only pattern that avoids the duplicate-insert problem.
